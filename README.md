# Feature Dataset Schema (Short)

This folder contains ML-ready feature datasets generated by `feature_engineering.py`.
All datasets are CSV with one header row. Tiers are stored as title-case strings.

## rank_features.csv
- Row: one per player (`puuid`)
- Label: `tier`
- Columns:
  - `puuid` (str)
  - `avg_kda` (float)
  - `avg_cs_per_min` (float)
  - `avg_gold_per_min` (float)
  - `avg_damage_per_min` (float)
  - `avg_vision` (float)
  - `avg_vision_per_min` (float)
  - `avg_kill_participation` (float)
  - `team_first_blood_rate` (float)
  - `team_first_tower_rate` (float)
  - `team_first_dragon_rate` (float)
  - `player_first_blood_rate` (float)
  - `win_rate` (float)
  - `champ_pool_size` (int)
  - `main_role` (str)
  - `matches_used` (int)
  - `tier` (str)

## progression_features.csv
- Row: one per player (`puuid`)
- Task: predict climb/decline based on deltas between older vs recent matches
- Columns:
  - `puuid` (str)
  - `delta_winrate` (float)
  - `delta_kda` (float)
  - `delta_cs` (float)
  - `delta_gold` (float)
  - `delta_damage` (float)
  - `delta_vision` (float)
  - `delta_kill_participation` (float)
  - `delta_team_first_blood` (float)
  - `delta_team_first_tower` (float)
  - `delta_team_first_dragon` (float)
  - `delta_player_first_blood` (float)
  - `win_streak` (int)
  - `matches_used` (int)

## smurf_features.csv
- Row: one per player (`puuid`)
- Label: `tier` (use for tier-normalized baselines)
- Columns:
  - `puuid` (str)
  - `tier` (str)
  - `winrate_zscore` (float)
  - `kda_zscore` (float)
  - `dmg_share` (float)
  - `gold_share` (float)
  - `avg_game_time` (float)
  - `champ_mastery_entropy` (float)
  - `avg_kill_participation` (float)
  - `avg_gold_per_min` (float)
  - `avg_damage_per_min` (float)
  - `avg_vision_per_min` (float)
  - `team_first_blood_rate` (float)
  - `team_first_tower_rate` (float)
  - `team_first_dragon_rate` (float)
  - `player_first_blood_rate` (float)

## match_features.csv
- Row: one per team per match (`match_id`, `team_id`)
- Label: `team_win` (0/1)
- Columns:
  - `match_id` (str)
  - `team_id` (int)
  - `team_win` (int)
  - `rank_diff` (float)
  - `kda_diff` (float)
  - `cs_diff` (float)
  - `gold_diff` (float)
  - `damage_diff` (float)
  - `vision_diff` (float)
  - `kill_participation_diff` (float)
  - `gold_per_min_diff` (float)
  - `damage_per_min_diff` (float)
  - `vision_per_min_diff` (float)
  - `first_blood_diff` (float)
  - `first_tower_diff` (float)
  - `first_dragon_diff` (float)
